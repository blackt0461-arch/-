# 動画かるく（shrink）仕様

画面の名前：**動画かるく**（Claude に渡す動画・画像を軽くする）

kotetsuworks.com/shrink/ ・ KOTETSU WORKS
本人の希望（2026-11-12）：「動画を資料として Claude に渡したいとき、データ量が多すぎて渡せない。不要な要素を取り除けるサイトがほしい」

## 1. 決めたこと（本人と 2026-11-12）

| 項目 | 決定 |
|---|---|
| 主に渡すもの | 練習・プレーの動画、画面録画（1〜5分が多い） |
| 使う機械 | iPhone とパソコンの両方 |
| 渡す先 | Claude のアプリ（iPhone）、Claude Code |
| メインの機能 | 動画の大事な場面を画像にして、**数枚のまとめ画像**に並べる |
| サブの機能 | 動画のまま画質・大きさを下げる（音は消す） |
| 操作 | おまかせ（入れるだけ）＋必要なときだけ細かい設定を開く |
| 音声 | 今回は扱わない（出す動画は音なし） |
| 本人のひと言 | 場面ごとの画像をバラバラにダウンロードして渡すのは手間 → まとめ画像＋共有ボタンで1回で渡せるようにする |

## 2. Claude が受け取れるもの（公式資料で確認・2026-11-12）

- Claude のアプリ／claude.ai：1ファイル 500MB まで、1つの会話に 20 ファイルまで。画像は JPEG・PNG・GIF・WebP、1枚 10MB・8000×8000 px まで。
  https://support.claude.com/en/articles/8241126-upload-files-to-claude ／ https://platform.claude.com/docs/en/build-with-claude/vision
- 画像は長い辺が大きすぎると Claude 側で縮められる（新しいモデルは長い辺 2,576 px まで、それ以外は 1,568 px まで）。→ まとめ画像は長い辺 2,576 px 以下で作り、こちらで縮めておく。
  https://platform.claude.com/docs/en/build-with-claude/vision
- **動画（mp4/mov）を Claude のアプリや Claude Code が読めるとは、公式資料には書かれていない。** 公式には「動画はこま（画像）に分けて渡せば分析できる」とある。→ メインは「場面を画像に」にする。
  https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices
- Claude Code：画像は貼り付け・ドラッグ・ファイルの場所で渡せる。PNG・JPEG・GIF・WebP を読める（HEIC は読めない）。
  https://code.claude.com/docs/en/common-workflows ／ https://code.claude.com/docs/en/tools-reference

## 3. 画面と流れ

1. 動画（または画像）を選ぶ（iPhone は写真から、パソコンはドラッグでも可）。
2. おまかせで「まとめ画像」を作る。進み具合を表示。
3. できたまとめ画像を表示。ボタン：
   - **「Claude に送る」**（iPhone など共有できる機械）：共有シートが開き、全部のまとめ画像を1回で Claude アプリへ渡せる。
   - **「コピー」**（1枚ずつ）：Claude Code やブラウザに貼り付けられる。
   - **「保存」**：まとめて保存（パソコンは1つずつダウンロード）。
   - 何MBから何MBになったかを表示。
4. 「細かい設定」（ふだんは閉じておく）
   - 場面の選び方：おまかせ（画面が大きく変わったところを優先）／一定間隔（秒数を指定）
   - 1枚に並べる数：4（文字をはっきり読ませたい時）／9（標準）／16
   - 場面の数の上限（標準 36 = 9×4枚）
   - 使う範囲（始め〜終わり）
   - 白黒にする
   - 各場面に時間（例 1:23）を入れる（標準オン）
5. 別タブ「動画のまま軽く」：画質（小・中・大）を選ぶだけ。音は消す。mp4 で保存。
   - 注意書き：「Claude は動画を直接読めないことがあります。そのときはまとめ画像を使ってください」
6. 画像を入れたとき：長い辺 2,576 px に縮めて JPEG にする（HEIC も変換）。

## 4. おまかせの中身

- 動画を一定間隔で軽く見て、前の場面との違いが大きい所を「大事な場面」として選ぶ。足りなければ均等に補う。
- 場面の数：長さに合わせて自動（1分 → 約12、5分以上 → 36）。
- まとめ画像：1枚 3×3、長い辺 2,576 px 以下、JPEG（だいたい 1枚 1MB 以下）。左上に時間を入れる。

## 5. 作り方のきまり

- ファイルはスマホ・パソコンの中だけで処理し、どこにも送らない。記録も取らない。0円で動く。
- 場面の取り出し・まとめ画像：ブラウザの標準機能（video・canvas）だけで作る。部品なし。
- 「動画のまま軽く」：Mediabunny 1.62.1（MPL-2.0 ライセンス、https://github.com/Vanilagy/mediabunny ）を CDN（jsDelivr）から版を固定して読み込む（手を加えずに使う）。ブラウザの動画変換機能（WebCodecs）を使う。使えない古いブラウザでは、このタブだけ「この機械では使えません」と出す。
- 1ファイル 25MB を超える部品は置かない。ファイルは shrink/ フォルダの中だけ。
- 公開は窓口（ROOMIN 代表）セッションが行う。tools/deploy/build.js の TOP_DIRS に 'shrink' を足す。
