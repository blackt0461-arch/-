# よていパズル（引きつぎ用）

（前の名前は「まいにち予定表」。2026-11-08 に本人が「よていパズル」に決めた。保存データのキーは前のまま）

妹さんが1日の予定をブロックで組み立てて、画像にして親に送るためのWebアプリです。
`index.html` が本体（サーバーやデータベースは不要）。ホーム画面に追加するためのファイルがそばにある。

## 置き方
- `yotei/` フォルダの中身をまるごと置く（`index.html`・`manifest.webmanifest`・`sw.js`・アイコンの png）。場所の指定はすべて相対なので、どのフォルダでも動く。
- **HTTPS で公開すること**（「LINEで送る」ボタン＝Web Share API はHTTPSでないと動かない）。
- 外部から読みこむのは Google Fonts（M PLUS Rounded 1c / DM Mono）だけ。読めなくても代わりの字体で動く。

## データの保存
- ブラウザの localStorage に保存（キー：`mainichi-yotei-v2`）。**その端末のそのブラウザだけ**に残る。
- スマホとパソコンで予定を共有する仕組みはまだない（ユーザーとは「まずは機械ごと。ドメインに移すときに共有を足す」と決めている）。足す場合はログイン＋サーバー保存が必要。
- 保存データの形（JSON）：
  - `name` 名前（画像に入る）
  - `genres` ジャンル `[{id,n,c}]`
  - `presets` 予定ブロックの種類 `[{id,g,n,c,d(分),use(選んだ回数)}]`
  - `days["YYYY-MM-DD"] = {blocks:[{id,pid,n,c,s(開始・0時からの分),d(分),free?}], tray:[{pid,n,c,d}]}`
  - `sent["YYYY-MM-DD"]` 親に送った印 / `tut` 案内を見たか / `view` タイルorタグ / `zoom` 拡大の段階

## 画面と決まっていること（ユーザーと相談して決めた内容）
- 見た目：パズルふう（夜空の背景、つやのあるブロック）
- ホーム：日付・週のならび（上に「‹ 前の週／今週・来週・先週／次の週 ›」で週を切りかえ。2026-11-08 本人の希望「来週の予定も立てたい」。見る画面も同じ）・横向きで縦に高い予定表（いま/つぎ）・夜20時以降は「明日の計画」カード・下に「計画をつくる/なおす」「見る」「親に送る」
- やることを選ぶ：タイル⇔タグ切りかえ、ジャンル分け、最初はチェックなし、よく選ぶ順、決定は右上、各ジャンルに「＋作る」、「へんしゅう」でタイル/ジャンルを消す（もどすあり）、「＋ジャンルを作る」
- ブロックを置く：左に手持ち（細め）、まん中に0〜24時の時間表、右に上下移動用のバー（1日の縮小図）。**指では0.3秒長押しで持ち上がる**（2026-11-08 本人の希望「簡単に動きすぎる」。長押し前に指を動かすと、ふつうのスクロールになる。マウスはそのままドラッグ）。ドラッグで置く・5分単位で吸着（2026-11-08 本人の希望。前は15分。前後のブロックと10分以内ならくっつく）・重ねると割りこんで後ろを押す・24時をこえると置けない。手持ちタップで最後尾にくっつけて置く。下のつまみで長さ：後ろにくっついたブロックがあれば境目が動く（後ろの終わり時刻は固定）、なければ次のブロックの手前まで。縮めても後ろは動かない。ブロックタップで開始/長さ±5分・**色**・手持ちにもどす・消す。色は12色の見本＋「＋」で好きな色。色を変えると、その種類（例「宿題」）の色が選ぶ画面・手持ち・どの日のブロックもまとめて変わる（2026-11-08 本人の希望）。＋−で5段階の拡大。「すきまをつめる」「すきまを自由時間に」。
- 見る：時刻と予定のリスト（いまが光る・終わったものはうすく）
- 親に送る：白い手帳ふうの画像（1日 / 1週間）。「LINEで送る」（Web Share API・ファイル共有）、「画像を保存」（ダウンロード）、「全画面で表示」（スクショ用）、画像の長押し。
- 使い方：初回だけ、選ぶ画面と置く画面で指さしの案内（スキップ可・設定から再表示）

## ホーム画面に追加（PWA）
- `manifest.webmanifest`：名前「よていパズル」、縦向き、夜空の色。アイコンは `icon-192.png` / `icon-512.png` / `icon-maskable-512.png`（Android の丸や角丸に切られても欠けないよう、絵を80%に縮めたもの）。iPhone 用は `apple-touch-icon.png`（180）。
- アイコンの元の絵は `icon.svg`（案A「時間のブロック」。自作の図形だけ）。変えたら png を作り直す。
- `sw.js`：電波がなくても開けるようにする仕組み。画面はまずネットから取り、だめなら保存した分を出す（新しい版はすぐ反映）。アイコン・字体は保存した分を先に使う。保存の名前 `yotei-v1`、ファイルを足したら `SHELL` に足して番号を上げる。HTTPS（または localhost）のときだけ動く。
- 設定画面に「ホーム画面に追加する」：Android の Chrome ではそのまま追加の確認が出る。iPhone などでは手順を表示。ホーム画面から開いているときはボタンを出さない。

## claude.ai の試し版との違い
- 試し版では「LINEで送る」「画像を保存」はブラウザの制限で動かなかった。独自ドメイン（HTTPS）では動くはず。iPhone の Safari / Android の Chrome で一度ためしてほしい。
