## ルール
- 盤面は六角形のマスでできた島。人数が多いほど大きくなる（2人 61マス 〜 16人 271マス）。
- マスの種類
  - 草原：ふつう。守り +0
  - 森：守り +1
  - 山：守り +2
  - 湖：だれも取れない
  - ルーンの石：3点。持っていると毎ラウンド兵が +1。だれのものでもない時は守り +2
  - お城：各自のスタート地点。2点。守り +3
- 1ラウンドの流れ（全員同時）
  1. 作戦（35秒）：配られた兵を、自分のマスか、自分のマスのとなりに置く。魔法カードを1枚まで使える。全員が「決定」したら、時間前でも次へ。
  2. 結果：マスごとに強さをくらべる。強さ＝置いた兵の数（持ち主は ＋1 と土地の守りが足される）。いちばん強い人のものになる。引き分けなら持ち主のまま（持ち主がいなければ、だれのものにもならない）。だれのものでもないマスも、土地の守り（森1・山2・ルーンの石2）より多い兵でないと取れない。
  3. 兵は毎ラウンド配り直し（次のラウンドには残らない）。
- 配られる兵：3 ＋ 持っているマス6つごとに1 ＋ ルーンの石1つごとに1 ＋（点数が下半分の人は）2。
- 途中から入った人は、最初の2ラウンドだけ兵が1少ない。
- 土地がなくなっても負けではない。次のラウンドは、だれのものでもない好きなマスに兵を置ける（ふっかつ）。
- 18ラウンド（約13分）で終わり。点数＝マス1つ1点 ＋ ルーンの石3点 ＋ お城2点 ＋ 宝のカードの点。いちばん多い人の勝ち。
- 部屋を作った人が「短め 12 / ふつう 18 / 長め 24」ラウンドを選べる。
- 途中から入った人も、次のラウンドから、空いている場所にお城をもらって参加できる。

## サイコロ・宝箱・イベント（本人の決定 2026-11-14）
- サイコロ：とりあいのマス（2人以上が兵を置いたマス）だけ。それぞれの兵に 0〜2 が足される（小さめ）。
- 宝箱マス：はじめに「人数÷2＋1」こ（2こ以上）、お城とルーンの石から離れた空き地に置く。取った人がカード1枚（順位が下ほど強いカード）か2点をもらう。取られた宝箱は消え、足りない時は毎ラウンド35%で別の空き地に出る。
- イベント：3ラウンド目から、毎ラウンド20%（2回続けては起きない）。予告なしで、結果の時に起きる。
  - 🐲 ドラゴン：だれかの土地が3マス空き地に（お城・結界はのぞく）
  - 🌊 大波：海ぞいの土地が4マス空き地に
  - 🪙 金貨の雨：みんな1点
  - ✨ ルーンの輝き：ルーンの石1つにつき1点
  - 🧚 妖精のおくりもの：みんなカード1枚
- 結果の見せる順番：カード → サイコロ → マスの塗りかえ → 宝箱 → イベント → 点数と順位。
- バランス（足した後）：半分の時点の1位が勝つ 44〜48%、1位の入れかわり 6〜9回、カードの強さ 16〜29% のまま。

## わかりやすさの直し（本人の要望 2026-11-14：「どんなゲームか説明が足りない」「なぜ取れないのかわからない」「サイコロは1人ずつ演出がほしい」）
- はじめて開いた時に、絵つきの紹介（5ページ）：ようこそ（取り合って点数で勝つ）→ 同時に兵を置く → 多い方が勝ち・守る側は強い（例 3＞2）→ 運で逆転（カード・サイコロ・宝箱・イベント）→ 点数のかぞえ方。「遊び方を見る」とメニューからいつでも見られる。最後に「くわしいルール」。
- 兵を置く時：光るマスに「取るのに要る兵」の小さい数字。置いたマスには「あと○」（オレンジ）か「取れる」（緑）の札。説明文に「守り○（持ち主+1・森+1）→ ○人で取れる。いま○人」。
- 結果の時：「攻めた○マス：取れた○・取れず○」と「なぜ？」ボタン。押すと、自分が兵を置いたマスごとに「あなた 3＜守り 4（持ち主の兵1＋持ち主+1＋森+1＋サイコロ1）」のような内訳。盤面のマスをタップすると、そのマスの勝負も見られる。メニューの「前のラウンドの結果」からも見られる。
- サイコロのとりあい：とりあいのマスごとに札を出し、1人ずつサイコロを転がす（＋0〜＋2）。守る人・土地の守りの行も出して、合計をくらべ、勝った人を光らせる。自分のマスを先に、3か所まで（ほかは「ほかに○か所」）。
- 結果を見せる時間は、演出の長さ＋読む時間（約2.5秒）。親が計算する（最大24秒。タップでとばせる）。
- 試合のデータ（last.fights）に、マスごとの勝負の内訳を入れた。

## 3Dジオラマの盤面（本人の依頼 2026-11-14：「3Dを上から俯瞰して、リアルな感じに」「ジオラマ風」）
- board3d.js（three.js 0.169.0。ROOMIN と同じ版。index.html の importmap で読む）。木のお盆の上の島を、ななめ上から見おろす。光と影（きれいの時）、マスの高さ（草原・森・山・ルーン・お城でちがう）、山・木・ルーンの石・お城・宝箱・兵のコマ。
- マス目：マスのすき間がうっすら六角形の線に見える。持ち主は地面の色とふち（濃い色の輪）で分かる。お城の旗は持ち主の色。兵を置けるマスは光る輪。
- わかりやすさの表示はそのまま（取るのに要る兵の数字・置いた数・「あと○／取れる」の札・カードの的）。3Dの上に字の札を重ねて出す。
- 操作：指でずらす・2本指で広げる・タップでマスを選ぶ・長押しで戻す。マスが小さい時は最初のタップで広がる。「全体」で元の見え方に。
- 演出：結果の時、演出の場所へカメラが動き、終わると元の見え方にもどる。
  - カード：炎の竜（ドラゴンが飛んできて火をふく）・守りの結界（光のドーム）・転移の門（光の輪が回って上る）・勇者の加勢（剣が3本ふってくる）・運命のサイコロ（大きなサイコロが転がる）・大嵐（黒い雲と雨）・竜の宝（宝石がふき出す）
  - イベント：ドラゴン（飛んで火をふく）・大波（波の壁が島に寄せる）・金貨の雨（金貨がふる）・ルーンの輝き（光の柱）・妖精（お城を回って光のつぶ）
  - 宝箱（ふたが開いて光のつぶ）・マスを取った（ぽんっとはねて土ぼこり）・とりあい（光の輪）
- 画質（メニューの「画質」）：3D（きれい：影あり・高い解像度）／3D（かるい：影なし・解像度ひかえめ）／2D（今までの絵本の地図）。WebGL が使えないスマホは自動で2D。
- 何も動いていない時は描きなおさない（電池にやさしい）。光るマスだけの時は少しゆっくり描く。
- Meshy のモデル（お城・兵・ドラゴン・木・宝箱・ルーンの石・妖精。keiba 担当が生成、本人の希望でリアル寄り）を runeland/models/ に置いて使う。本人の決定で、軽くせず元のファイルのまま使う（約22MB）。ない物は自作の形で表示（models/README.md）。
  - 金属あつかいで暗く見えたので、木や石らしい見え方に直した。木・宝箱・ルーンの石は少し明るく太く。お城は城壁がマスに収まる幅。
  - 兵は1マスに1体（プレイヤーの色の台に乗る。数は札で表示。全部で60体まで）。木は1マスに1本。
  - 画質「かるい」では、お城・兵・木は自作の軽い形。
- カクつき見守り：「きれい」で描く間隔が長すぎる時（ふつう約48ms＝約20コマ/秒より遅い）、自動で「かるい」に切りかえて知らせる。メニューで画質を自分で選んだ人には自動で切りかえない。

## 魔法カード（運の要素）
はじめに2枚。毎ラウンド1枚ずつ配られる（手札は3枚まで。あふれたら古い方がなくなる）。1ラウンドに1枚まで使える。
順位が下の人ほど「炎の竜・勇者の加勢・転移の門」が出やすい（逆転のしかけ）。
| カード | 効果 |
|---|---|
| 炎の竜 | 選んだマスと、となりの同じ人のマス2つまでを、空き地にもどす（お城はのぞく。結果をくらべる前に起きる） |
| 守りの結界 | 選んだ自分のマスと、そのとなりの自分のマスは、このラウンド取られない |
| 転移の門 | このラウンドは、どこにでも兵を置ける。兵 ＋2 |
| 勇者の加勢 | このラウンドの兵 ＋4 |
| 運命のサイコロ | このラウンドの兵 ＋1〜6（サイコロで決まる） |
| 大嵐 | ほかの全員の、いちばん多く兵を置いたマスで、兵が2減る |
| 竜の宝 | すぐに 2点 もらえる（最後の点数に足される） |
同じラウンドに何人も使った時は、炎の竜 → 結界 → 大嵐 の順に起きる。結界のマスに炎の竜は効かない。

## つながる仕組み
- Supabase（プロジェクト zmteazudhtnzvfvmndqn・東京）の Realtime（Broadcast と Presence）だけを使う。**DB には何も保存しない**ので、テーブルや SQL の追加はない。
  - だれもいなくなった部屋は、その場で自然に消える。
- 公開用の鍵は skate と同じ sb_publishable_（runeland/relay-config.js）。秘密の鍵は使わない。
- 部屋の中でいちばん早く入った人のスマホが「親」になって、結果の計算と配る役をする。親がぬけたら、次に早く入った人が自動で引きつぐ（全員が最新の盤面を持っているので、続きから遊べる）。
- 送るのはニックネーム（12文字まで）・色・置いた兵・使ったカードだけ。本名やメールは集めない。
- 盤面の地形は「種」の数から全員のスマホで同じものを作るので、送るのは持ち主の並びだけ（小さい）。

## 画面
- はじめの画面：ニックネーム、「部屋を作る」「番号で入る」
- 待合室：部屋の番号・招待リンク（共有ボタン）、入っている人、ラウンド数の選択（親だけ）、「はじめる」
- 待合室：コンピューターを「やさしい・ふつう・つよい」で足せる（親だけ。✕で外せる）。合わせて16人まで。
- 見た目：絵本のような地図（羊皮紙の色、手がき風にゆれたマスの角、やわらかい海岸）。字は丸い字（M PLUS Rounded 1c。読めない時はスマホの字）。
- ゲーム：上は見るだけ（ラウンド・残り時間の輪・自分の点・決定した人数）。押すものは下（手札・戻す・決定）にまとめ、ボタンは48px以上。
  - 決定ボタンの字が変わる（決定（兵あと3）→ 決定！ → 決定ずみ ✓）。
  - 盤面：2本指で広げる・指でずらす。マスが小さすぎる時は、最初のタップで広がる。長押しで兵を1つ戻す。
  - 名前の列：まだ考え中の人は「…」、決定した人は「✓」。1位に王冠。
  - 残り10秒で輪が黄色、5秒で赤。カチカチ音が速くなり、最後の3秒はふるえる（Android）。
- 結果（4〜9秒、タップでとばせる）：カードを1枚ずつ見せる → 取られたマスを真ん中から順にぽんっと塗りかえ → 点数と順位の変化（▲▼・並びがすべる）。
  「1位交代！」「いっきに○マス！」「最終ラウンド！」の大きな札が出る。
- はじめての案内（1回だけ）：「光っているマスをタップ」→「決定」→（2ラウンド目）「カード」。やったら次へ進む。8秒何もしないと、置けるマスがふわっと光る。
- おわり：称号（ひろい国の王・いっきの大攻め・魔法つかい・ルーンの守り手・大逆転・かたい守り。なるべくいろいろな人に）を1つずつ → 表彰台（3位→2位→1位）→ 紙ふぶき。
- 音：効果音と音楽（やさしい3拍子。最後の3ラウンドは少し速く・きんちょう感）。どちらもメニューで消せる。外の音源は使わず、その場で作る。

## バランスを確かめた結果（2回目・2026-11-14。tests/balance.mjs）
| 見たもの | 直す前 | 直した後 |
|---|---|---|
| 半分の時点の1位が、最後も勝つ（4人） | 58% | 約50% |
| 1位の入れかわり（1ゲーム） | 3〜4回 | 6〜9回 |
| 1人だけ同じカードばかりの時の勝率（4人。ふつうは25%） | 大嵐 97%・竜の宝 70%・転移の門 1% | どのカードも 18〜29% |
| お城の近くにルーンの石があるか | 近い方が少し有利 | ほぼ同じ |
| 途中から入った人の勝ち（8人。ふつうは12%） | 0〜2% | 約7%（決めたとおり少し不利） |
| 強さ（いろいろ混ぜて） | やさしい 0%・ふつう 14%・つよい 40% | 7%・18%・29% |
直したこと：兵の増え方をゆるく（4マス→6マスごと）、点数が下半分の人に兵＋2、カードの効果を調整（大嵐を「いちばん多く置いたマスで−2」、竜の宝を3点→2点、転移の門に兵＋2、炎の竜は周りも燃える、守りの結界は周りも守る）、途中参加の兵の減らし方を−2→−1。
