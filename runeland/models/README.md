# runeland/models

出典：Meshy で生成（本人のアカウント、keiba 担当が作成。コミット f984790・9db7916、2026-11-14）。本人の希望で「リアル・洋風・細かさ高め」。
本人の決定（2026-11-14）で、軽くせず元のファイルのまま使う（合計 約22MB）。
