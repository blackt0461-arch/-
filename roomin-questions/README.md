# ROOMIN 問題バンク（4択）

ROOMIN（study-room）用に作った4択問題の置き場です。**アプリにはまだ組みこんでいません。**
このフォルダは公開ページ（study-room / study-room-beta）の外にあるので、置いただけでは画面に出ません。

## ROOMIN 担当の AI へ（まずここを読む）

- 問題は `INSTRUCTIONS.md`（ユーザーが用意した「問題づくり指示書」）のルールで作っています。
- 1ファイル＝1単元。`data/<subject>/<genre>/<unit>.json` に、指示書どおりの JSON 配列で入っています。
- 1問の形（項目の順番もこのとおり）:

```json
{ "id": null, "subject": "math", "genre": "数学I", "unit": "二次関数", "grade": "hs1",
  "level": 1, "text": "…", "choices": ["…","…","…","…"], "answer": 0, "explain": "…。" }
```

- 下書きは `src/*.txt`（1行1問の短い書き方）。`node roomin-questions/tools/build.js` で `data/` の JSON を作り直す。直すときは src を直して build する（data を直接直すと、次の build で消える）。
- 確かめ: `node roomin-questions/tools/check.js`（形・選択肢4つ・answer の範囲・LaTeX/Markdown なし・genre 名・同じ問題文の重複を見る。`-v` で注意も表示）
- 1本にまとめる: `node roomin-questions/tools/check.js --merge` → `roomin-questions/dist/all.json`

### いまのアプリとのちがい（組みこむときに必要な作業）

いまのアプリ（`study-room-beta/js/subjects/*.js`）は形が少しちがいます。組みこむときは次に気をつけてください。

| | いまのアプリ | この問題バンク |
|---|---|---|
| id | `'math-001'` のような文字 | `null`（アプリ側で付ける） |
| 教科 | ファイル（math.js など）で分ける | `subject` 項目 |
| ジャンル | なし | `genre`（数学I・化学基礎 など）。教科 → ジャンル → 単元 の3段階で見せる想定 |
| 学年 | hs1 / hs2 | hs1 / hs2 / hs3 |
| 教科の種類 | 数学・英語・化学・国語・社会（物理は別形式） | ＋物理（4択）・生物・地学 |

- 物理はいまのアプリでは「文字を割り当てる→公式を選ぶ」の別形式です。ここの物理は4択なので、教科えらびでの扱い（4択の物理を別に出すか）はユーザーに聞いてください。
- 生物（bio）・地学（earth）はいまのアプリにない教科です。教科えらびに足す必要があります。
- 既存の約500問（js/subjects/）と内容が重なるものがあるかもしれません。
- 組みこむときも、CLAUDE.md の「テスト版 → 管理者がためす → ユーザーの許可 → 本番」の順にしてください。

### 中身の正しさについて

作るときに1問ずつ解き直して確かめていますが、AI が作ったものなので、まちがいが残っている可能性があります。
ユーザーや本人（妹さん）から「この問題おかしい」と言われたら、その問題を直してください。
