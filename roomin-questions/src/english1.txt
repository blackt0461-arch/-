1 ;; (　)に入る語句を選べ。\nHe usually (　) to school by bus. ;; *goes ;; go ;; gone ;; going ;; usually は習慣を表すので現在形。主語が三人称単数なので goes。

1 ;; (　)に入る語句を選べ。\nI (　) a movie with my friends yesterday. ;; *saw ;; see ;; have seen ;; seen ;; yesterday のような過去を表す語があるときは過去形。現在完了は yesterday といっしょに使えない。
1 ;; (　)に入る語句を選べ。\nI (　) in Osaka since 2020. ;; *have lived ;; live ;; lived ;; am living ;; since 2020（2020年から今まで）は継続を表すので現在完了形。
1 ;; (　)に入る語句を選べ。\n(　) you ever been to Kyoto? ;; *Have ;; Did ;; Are ;; Do ;; been と ever があるので「行ったことがありますか」という経験の現在完了。疑問文は Have を前に出す。
1 ;; (　)に入る語句を選べ。\nWhen I came home, my mother (　) dinner. ;; *was cooking ;; is cooking ;; cooks ;; has cooked ;; 帰ったとき（過去のある時点）に進行中だった動作なので過去進行形。
2 ;; (　)に入る語句を選べ。\nI will call you when he (　) home. ;; *comes ;; will come ;; came ;; coming ;; 時や条件を表す副詞節（when 〜、if 〜）の中では、未来のことも現在形で表す。
2 ;; (　)に入る語句を選べ。\nI had already finished my homework when she (　). ;; *came ;; has come ;; comes ;; had come ;; 宿題を終えたのは彼女が来た時点より前なので過去完了。来たこと自体は過去形で表す。
2 ;; (　)に入る語句を選べ。\nI (　) here for three hours. I'm tired of waiting. ;; *have been waiting ;; am waiting ;; was waiting ;; waited ;; 3時間前から今までずっと待っている動作の継続なので、現在完了進行形。
2 ;; (　)に入る語句を選べ。\nBy the time you arrive, we (　) the work. ;; *will have finished ;; have finished ;; finished ;; had finished ;; 未来のある時点（あなたが着くとき）までに完了していることは未来完了形で表す。
2 ;; (　)に入る語句を選べ。\nShe lost the key that she (　) the day before. ;; *had bought ;; has bought ;; buys ;; was buying ;; 買ったのは失くした（過去）よりさらに前なので過去完了（大過去）。
2 ;; (　)に入る語句を選べ。\nI don't know if it (　) tomorrow. ;; *will rain ;; rains ;; rained ;; has rained ;; この if は「〜かどうか」の名詞節で、know の目的語。名詞節では未来のことは will を使う。
3 ;; (　)に入る語句を選べ。\nIt (　) for a week before it finally stopped. ;; *had been raining ;; has been raining ;; is raining ;; will have rained ;; やんだ（過去）時点まで1週間続いていた動作なので、過去完了進行形。
3 ;; (　)に入る語句を選べ。\nTen years (　) since we first met. ;; *have passed ;; are passing ;; will pass ;; had been passed ;; since 〜 があり、今までに10年たったので現在完了形。pass は自動詞なので受け身にしない。
3 ;; (　)に入る語句を選べ。\nI (　) him for ten years. ;; *have known ;; have been knowing ;; am knowing ;; know ;; know は状態を表す動詞なので進行形にしない。継続は現在完了で表す。

1 ;; (　)に入る語句を選べ。\nYou (　) wear a seatbelt in the car. It's the law. ;; *must ;; may ;; might ;; need not ;; 法律で決まっている義務なので must（〜しなければならない）。
1 ;; (　)に入る語句を選べ。\n"(　) I open the window?" "Sure, go ahead." ;; *May ;; Must ;; Need ;; Would ;; May I 〜? は「〜してもよいですか」と許可を求める表現。
1 ;; (　)に入る語句を選べ。\nShe will (　) swim next year. ;; *be able to ;; can ;; could ;; able to ;; 助動詞を2つ並べて will can とはいえないので、can のかわりに be able to を使う。
1 ;; (　)に入る語句を選べ。\nYou (　) not to eat too much. ;; *ought ;; should ;; must ;; had better ;; ought to の否定は ought not to。should・must・had better のあとに to はつかない。
1 ;; You don't have to come. の意味として正しいものを選べ。 ;; *あなたは来る必要はない ;; あなたは来てはいけない ;; あなたは来るべきだ ;; あなたは来るかもしれない ;; don't have to は「〜する必要はない」。「〜してはいけない」は must not。
1 ;; (　)に入る語句を選べ。\nIt (　) rain this afternoon. Take an umbrella just in case. ;; *may ;; must not ;; need not ;; has to ;; 「〜かもしれない」という推量の may。念のためかさを持っていく、という流れに合う。
2 ;; (　)に入る語句を選べ。\nHe (　) have been at the party last night. He was with me all evening. ;; *can't ;; must ;; should ;; may ;; can't have 過去分詞で「〜したはずがない」。一晩中自分といたので、パーティーにいたはずがない。
2 ;; (　)に入る語句を選べ。\nYou (　) have told me the truth yesterday. Why did you lie? ;; *should ;; must ;; can ;; will ;; should have 過去分詞で「〜すべきだったのに（しなかった）」。must have なら「〜したにちがいない」で文脈に合わない。
2 ;; (　)に入る語句を選べ。\nI would rather (　) at home today. ;; *stay ;; to stay ;; staying ;; stayed ;; would rather のあとは動詞の原形で「むしろ〜したい」。
2 ;; (　)に入る語句を選べ。\nYou had better (　) a doctor. ;; *see ;; to see ;; seeing ;; seen ;; had better のあとは動詞の原形。「〜したほうがよい」。
2 ;; (　)に入る語句を選べ。\nHe used to (　) tennis every Sunday. ;; *play ;; playing ;; played ;; plays ;; used to 動詞の原形で「以前はよく〜した」。be used to 〜ing（〜に慣れている）と区別する。
2 ;; (　)に入る語句を選べ。\nShe must (　) tired after the long trip. ;; *be ;; being ;; to be ;; been ;; 助動詞のあとは原形。must be で「〜にちがいない」。
3 ;; You need not have hurried. の意味として正しいものを選べ。 ;; *急ぐ必要はなかったのに（実際は急いだ） ;; 急いではいけなかった ;; 急いだにちがいない ;; 急いだかもしれない ;; need not have 過去分詞は「〜する必要はなかったのに（してしまった）」。
3 ;; (　)に入る語句を選べ。\nI suggested that he (　) a rest. ;; *take ;; took ;; taking ;; to take ;; suggest（提案する）に続く that 節では、(should) 動詞の原形を使う。
3 ;; He may well be angry. の意味として正しいものを選べ。 ;; *彼が怒るのももっともだ ;; 彼は怒ってもよい ;; 彼は怒ったほうがよい ;; 彼は怒ったにちがいない ;; may well 〜 は「〜するのももっともだ」「たぶん〜だろう」。may as well（〜したほうがよい）と区別する。
