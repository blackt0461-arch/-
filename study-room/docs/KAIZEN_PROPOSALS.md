# 改善の提案（本人の判断が必要なもの）

作りや遊び方を大きく変えるものは、ここに書いて本人に決めてもらう。

## 1. 保存データの大きさに上限をつける（安全）
- 問題：`sr_save` は送られてきたデータをそのまま保存する。大きさの上限がないので、悪意のある人が巨大なデータを送ると、保存先の容量を使い切られるおそれがある（家族で使う今は心配は小さい）。
- 案：`sr_save` の最初に `if pg_column_size(p_data) > 2000000 then raise exception 'too_large'; end if;` を足す（ふつうの人のデータは数十KB）。
- おすすめ：やる。ただし Supabase の設定を変える作業（SQL Editor で実行）が必要なので、本人の手が空いた時に。
