# 猫の3Dモデル（cat-model）

本物の猫の体のつくりを、骨から順に作りこんでいく3Dモデル。完成したモデルはゲーム（まずは「猫を動かす部屋」）で使う。

## 決まっていること（2026-11-06 にユーザーと決めた）

| 項目 | 決めたこと |
|---|---|
| 使い道 | ゲームのキャラクター。最初は家の中の部屋（ソファ・棚・キャットタワー・窓辺）で猫を自由に動かす |
| 見る場所 | ブラウザ（スマホは画面のボタン、PC はキーボード） |
| 作りこみ | 骨・筋肉・関節を本気で作る。内臓は形と位置だけ。皮ふと毛も作る |
| ゲームでの見え方 | 中身（骨・筋肉）は見せない。正しく作れているかは、この確認画面で開発者だけが見る |
| 動き | 歩く・走る・跳ぶ・登る・座る・寝る・丸まる・伸び・毛づくろい・狩り・遊ぶ・空中で体をひねって着地 |
| 動きの作り方 | 猫の研究データ（足を出す順番・関節の角度など）をもとに自作。段差では足の置き方を自動で合わせる |
| 放っておくと | 自分で毛づくろいしたり、丸まって寝たりする |
| 筋肉の計算 | 作るときに前もって計算してモデルに焼き付ける（スマホでも軽く動くように） |
| 毛 | 何層にも重ねた、ふんわりした立体の毛（スマホでは層を減らす） |
| 猫の種類 | 最初は短毛の茶トラ。写真から毛の色と柄を読み取る仕組みはそのあと。体型はつまみで調整 |
| 作る道具 | 開発用（Claude が使えればよい）。画面はなくてもよい |
| ファイル形式 | glTF（.glb）。ほかのゲームや Unity などでも使える |
| 進め方 | ①骨格 → ②筋肉 → ③皮ふと毛 → ④動き → ⑤部屋。段階ごとに確認画面で見せる |

## いまの段階：③ 皮ふと毛（① 骨格・② 筋肉はできあがり）

- `index.html` … 確認画面。回す・骨や筋肉をタップして名前を見る・名前でさがす・筋肉を層ごとに表示・筋肉をうすくする・ポーズを試す・分解する
- 公開先：https://blackt0461-arch.github.io/-/cat-model/
- `models/cat-anatomy.glb` … 全身の骨格＋筋肉＋内臓＋皮ふ（できあがったモデル）
- `tools/skeleton/` … 骨格と筋肉を作るプログラム

### 皮ふと毛（第3段階）

- **皮ふ**：骨・筋肉・内臓・詰め物（ひげのふくらみ・唇・鼻・あご・肉球・首・おなか）を 1mm の格子に描きこみ、外から包む面を取り出して作る（`skin.js`）。
  - すきまを閉じる大きさを場所で変える：胴（上腕は肘まで・太ももは膝まで胴の皮ふの中）は 15mm、手足の先・しっぽは 4.5mm。
  - 皮ふの下の脂肪の厚さ：胴は約 4.6mm、手足の先は 2mm。
  - まぶたのすきま（アーモンド形）と鼻の穴は、面を切って作る。
  - 骨と一緒に動く重みは、近くの骨・筋肉の重みを集めて皮ふの上でならす。
- **茶トラ柄**：皮ふの頂点の色に入れる（`tabbyColor`）。背中の濃い線、背中から下へ流れる縞、足としっぽの輪の縞、しっぽの先は濃い色、ほおの線、おでこの細い線、鼻づら・あご・おなか・足の内側はクリーム色、鼻と肉球はピンク、まぶたのふちは黒っぽい。
- **毛の長さ**：頂点の色の A（1 で 12mm）。胴 約8mm、おなか 約10mm、頭 約3.5mm、耳 約2mm、足先 約3mm、しっぽ 約8mm、鼻・肉球 0。
- **毛の見せ方**（確認画面）：皮ふを少しずつ外へずらした層を重ねる（PC 26 層、スマホ 12 層）。各層で毛の断面（約 0.4mm）の点を残し、毛ごとに長さを変え、根元は暗く・先は明るくする。毛は後ろ・下へ流れる。
- **顔**：眼球（金色の虹彩・縦長のひとみ）、耳（内側はピンク）、ひげ（口のまわり 12 本・まゆの上 3 本・ほお 1 本 ×左右）。
- **内臓（形と位置）**：脳・肺・心臓・肝臓・胃・脾臓・小腸・大腸・腎臓・膀胱・気管・食道。

- 胴：最長筋・腸肋筋・棘筋/多裂筋・広背筋・外腹斜筋・内腹斜筋・腹直筋・肋間筋・横隔膜
- 肩と前足：僧帽筋・鎖骨上腕筋・菱形筋・腹鋸筋・腹側肩甲挙筋・三角筋・棘上筋・棘下筋・小円筋・大円筋・肩甲下筋・上腕三頭筋・肘筋・上腕二頭筋・上腕筋・胸筋群・腕橈骨筋・橈側手根伸筋・総指伸筋・外側指伸筋・尺側手根伸筋・尺側手根屈筋・橈側手根屈筋・浅指屈筋・深指屈筋・円回内筋・回外筋

### 筋肉の作り方

- `muscles.js` … 筋肉ごとに、骨の上の点（起始 → 通り道 → 停止）をつないだ「すじ」と、太さを決める。骨の座標は骨を作ったときと同じ座標（例：上腕骨の近位から何 mm、前へ何 mm）で書く。
- `muscle.js` … すじを管にする（腱 → 筋腹のふくらみ → 腱）。板のような筋肉（広背筋・腹斜筋など）は、となりのすじとのあいだを膜でうめる。骨と軟骨にめりこまないように削る。
- 骨と一緒に動かす：筋肉の各頂点を、近いすじの点がつく骨に重みづけする（glTF のスキン）。関節をまたぐ筋肉は、まんなかで両方の骨にまたがって伸び縮みする。
- 腱の部分は白っぽい色（頂点の色）にしてある。
- `build.js` は 4 つの CPU で手分けして作る（全部で約2分）。`--mus=Biceps,Triceps` で一部の筋肉だけ、`--muscles=0` で骨だけ。

### 大きさと参考にした数字

- 体重 4kg ほどの大人の猫。単位はメートル、y が上、+z が頭の向き。立った姿勢。
- 上腕骨 ÷ 大腿骨 ≒ 0.94、(上腕骨+橈骨) ÷ (大腿骨+脛骨) ≒ 0.90（Medycyna Weterynaryjna 82(2), 2026）
- 関節の動く範囲（Jaeger ら「Goniometry in normal cats」AJVR 2007）：肩 32〜163°、肘 22〜163°、手首 22〜198°、股 33〜164°、膝 24〜164°、足首 21〜167°。モデルの各関節に情報として入れてある（確認画面で骨をタップすると出る）。

### モデルの中のつくり（ゲームで動かすとき用）

- 骨1本＝ノード1つ。親子関係は関節のつながりどおり（仙骨が根元 → 腰椎 → 胸椎 → 頸椎 → 頭骨、仙骨 → 尾椎、仙骨 → 寛骨 → 大腿骨 → …）。
- 各ノードの原点は関節の中心。休んだ姿勢では回転なし。横軸（x）まわりに回すと、横から見た曲げ伸ばしになる。
- 肩甲骨は胸の骨と骨でつながっていない（筋肉だけでつく）ので、第3胸椎の子にしてある。
- ノードの `extras` に日本語名（ja）・ラテン語名（la）・部位（region）・左右（side）・種類（kind）・関節の動く範囲（rom）が入っている。

## 作り直し方

```sh
cd cat-model/tools
npm install          # 初回だけ（三角形を減らす道具 meshoptimizer）
node skeleton/build.js
# → cat-model/models/cat-anatomy.glb ができる（2分ほど）
```

オプション：`--only=skull,spine,thorax,forelimb,hindlimb`（一部だけ作る）、`--out=ファイル名`、`--fast`（粗く早く）、`--err=0.06`（形のずれの許容 mm）。

### 仕組み

1. `landmarks.js` … 設計図。背骨の中心線、椎骨の長さ、関節の位置。
2. `spine.js` `thorax.js` `skull.js` `forelimb.js` `hindlimb.js` … 骨ごとに、球・楕円体・円すい・板などを組み合わせて形を決める（距離関数 SDF）。くぼみ・穴（椎孔、閉鎖孔、顆上孔、眼窩など）は形を削って作る。
3. `mesher.js` … 形を細かい格子で調べて三角形の網にする（Surface Nets）。
4. `build.js` … 三角形を形を保ったまま減らし、左右を反転して両側を作り、`glb.js` で書き出す。

確認画面の URL オプション（開発用）：`?solo=骨の名前,…`（その骨だけ映す）、`?pose=spine:20,tail:60`、`?cam=x,y,z&tgt=x,y,z&fov=30`、`?ui=0`、`?model=ファイル名`。
