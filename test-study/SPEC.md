# テスト勉強（test-study）

大学の中間・期末テストの勉強アプリ。使うのは本人ひとり。スマホ中心。
公開先：https://blackt0461-arch.github.io/-/test-study/

## 決まったこと（2026-11 の聞き取り）

- 問題は **Claude がグーグルドライブのレジュメを読んで作る**。本人に頼まれたときに作る（自動ではない）。アプリの中で AI は使わない（お金がかからない）。
  - レジュメの場所：ドライブ「2026年後期」フォルダ（id `1bzzUiiheg72MBtZzh73Hm1PKrLw_iEHq`）の中に授業ごとのフォルダ。ファイル名は `第NN回_月-日_連番`。
- 分け方：**授業 → テスト（中間・期末）**。範囲は授業の回（第N回）でしぼれる。
- 問題の量：レジュメの内容を**すきまなくカバー**できるだけ作る。
- 勉強のしかた：ぜんぶ混ぜる／単語カード／小テスト（選択・穴うめ・計算＝自動採点）／記述・説明／まちがい復習。1回に解く数は毎回えらぶ（5・10・20・ぜんぶ）。
- 記述：スマホで打つ・紙に書いて写真、どちらもできる。お手本と「入れるべきポイント」を見て自分で⭕🔺❌。答えは保存し、あとで Claude にも採点してもらえる。
- 計算：答え（数字）を入れて自動採点し、解き方を出す。
- 持ち込み可のテストは「まとめシート」（印刷できる）も作る。
- 記録：いまはこの端末だけ。**次の版でドライブにも残す**（LYRIC BOOK と同じ Google Apps Script のやり方）。
- テストの日を入れると毎日の勉強量を決める機能：**2番目の版**で入れる。
- 名前は「テスト勉強」で仮。あとで決める。

## テストの形式（本人に聞いたこと）

| 授業 | 形式 |
|---|---|
| 電子回路I | 持ち込み可。理論の説明が中心になりそう（授業で計算はしていない）。中間は 2026-11 の第2週 |
| フーリエ解析 | 計算問題が中心 |
| 信号処理 | 証明・説明も出る |
| 通信理論 | 計算問題が中心、証明・説明も出る |

## 問題データの書き方

- `data/courses.json`：授業とテストの一覧。`{ "courses": [ { "id", "name", "tests": [ { "id", "name", "date"(任意 YYYY-MM-DD) } ] } ] }`
- `data/<授業id>/<テストid>.json`：`{ "note"(任意), "sheet"(任意・まとめシートのファイル名), "questions": [...] }`
- 問題の形（すべて `id`（テスト内で一意・変えない。記録とつながる）、`lecture`（例「第3回」）、`q`、任意で `explain`）
  - `card`：`a`（答え）
  - `choice`：`choices`（配列）、`answer`（正解の番号、0から）
  - `fill`：`answers`（正解として認める書き方の配列。ひらがな・別名も入れる）
  - `calc`：`answer`（数）、`tol`（ゆるす誤差の割合、ふつう 0.01）、`unit`、`answerText`（任意。表示用）
  - `written`：`model`（お手本）、`points`（入れるべきポイントの配列）
- 数式は `$...$`（文中）と `$$...$$`（1行）。KaTeX で表示する。JSON の中では `\` を `\\` と書く。
- まとめシート：`data/<授業id>/<ファイル名>.html`（`<h1>〜` から始まる中身だけ。印刷で A4 に収まる量を目安）。

## しくみ

- ふつうの HTML と JS（`js/app.js` 画面、`js/store.js` 記録）。組み立て作業なし。
- 記録：`localStorage` の `ts_records_v1`（問題ごとの回数・正解数・まちがい復習に入っているか）。記述の答えと写真は IndexedDB `test-study`。
- 問題の `id` を変えると記録が切れるので、直すときも `id` は残す。
