電子回路I 中間まとめ（第1〜6回）

記号：大文字＝直流（バイアス）、小文字＝小信号。$X/\!/Y=(1/X+1/Y)^{-1}$。$g_m^*=g_m+g_{mb}$。

① MOSFET の I–V 特性（第1回）

線形$V_{DS}\lt V_{GS}-V_T$：$I_D=\beta\left[(V_{GS}-V_T)-\frac{V_{DS}}{2}\right]V_{DS}$（$V_{DS}$ について上に凸の2次関数、頂点 $V_{DS}=V_{GS}-V_T$）
飽和$V_{DS}\ge V_{GS}-V_T$：$I_D=\frac{\beta}{2}(V_{GS}-V_T)^2(1+\lambda V_{DS})$（第1回は $\lambda$ を $\gamma$ と表記）
β・飽和電圧$\beta=\frac{W}{L}\mu_nC_{ox}$（サイズとプロセス）／$V_{DSAT}=V_{GS}-V_T=V_P=\Delta_{OV}$
$I_D$–$V_{GS}$線形（$V_{DS}$ 小）＝$V_T$ 付近から直線（傾き $\beta V_{DS}$）／飽和＝$V_T$ から放物線
  • ピンチオフ：ドレイン端の反転電荷 $Q_D=C_{ox}(V_{GS}-V_T-V_{DS})$ が $V_{DS}=V_{GS}-V_T$ で 0。以後チャネルはほぼ変わらず 電流一定。L が短いと実効チャネル長が縮み右上がり（チャネル長変調）。
  • 基板バイアス効果：基板がソースより低い → 空乏層のイオン化アクセプタ（負電荷）↑ → 反転層の電子↓ → 高いゲート電圧が必要 → $V_T$ 上昇（$I_D$–$V_{GS}$ が右へ）。$V_T$ はソース電位 $V_S$ の関数。
    $V_{TH}=V_{TH0}+\gamma\left(\sqrt{2\phi_F+V_{SB}}-\sqrt{2\phi_F}\right)$（$\gamma=0.3\sim0.4$）
  • 導出（参考）：平均電荷 $\bar Q=C_{ox}[(V_{GS}-V_T)-V_{DS}/2]$、電流＝$W\bar Q\times\mu_nE$、$E=V_{DS}/L$。

② $g_m$・増幅の原理・交流理論（第2回）

  • $g_m=\partial I_D/\partial V_{GS}$：線形 $\beta V_{DS}$／飽和 $\beta(V_{GS}-V_T)=\sqrt{2\beta I_D}$
  • 抵抗負荷：$V_{out}=V_{DD}-R_LI_D$。負荷線 $(0,V_{DD}/R_L)$–$(V_{DD},0)$。伝達特性：$V_{in}\lt V_T$ 遮断（$V_{out}=V_{DD}$）→ 飽和で急降下（高利得）→ $V_{out}\lt V_{in}-V_T$ で線形（利得小）。小信号利得＝傾き $dV_{out}/dV_{in}$、逆相。$R_L$ 大ほど急。
  • 交流理論の前提：単一周波数 $\omega$ の余弦波 → 振幅と位相だけ → フェーザ（複素数）。恩恵：$d/dt\to j\omega$（微分が掛け算）。
  • $q=Cv$、$i=C\,dv/dt$。$v=V_0\cos(\omega t+\varphi)$ → $i=\omega CV_0\cos(\omega t+\varphi+\frac{\pi}{2})$（$\omega C$ 倍・$\pi/2$ 進む）。
  • $V=V_0e^{j\varphi}$、$I=j\omega CV$、$Z_C=\frac{1}{j\omega C}$。戻すとき：$e^{j\omega t}$ を掛けて実部。
  • $j$ を掛ける＝$\pi/2$ 進む（4回で一周、$j$ で割ると遅れる）。$e^{j\theta}=\cos\theta+j\sin\theta$、$j=e^{j\pi/2}$。

③ OPアンプ・負帰還（第3回）

  • 1本線の増幅器記号は GND が省略。$v_{out}=Av_{in}$。
  • 負帰還：$A(x_{in}-\beta x_{out})=x_{out}$ → $A_{closed}=\frac{A}{1+A\beta}\approx\frac{1}{\beta}$（$A\beta\gg1$、帰還回路だけで決まる）。$\beta$：帰還率（$\le1$）、$A\beta$：帰還量。
    効用：①利得の安定化 ②帯域の拡大 ③入出力インピーダンス調整。プラスで戻すと正帰還。
  • OPアンプ＝差動増幅器：$v_{out}=A_d(v_{in}^+-v_{in}^-)$。理想：①入力抵抗∞ ②増幅率∞ ③仮想接地（仮想ショート）。
  • 反転増幅：$v_{out}=-A_dv_i$、$\frac{v_{in}-v_i}{R_1}=\frac{v_i-v_{out}}{R_2}$ → $v_i=\frac{R_2v_{in}+R_1v_{out}}{R_1+R_2}$ → $A_d\to\infty$ で $v_{out}=-\frac{R_2}{R_1}v_{in}$、代入で $v_i=0$（仮想接地）。帰還率 $\beta=\frac{R_1}{R_1+R_2}$。

④ 道具としての数学（第4回）

  • 小信号の線形近似：$I_D+i_d=\frac{\beta}{2}(V_{GS}+v_{gs}-V_T)^2$ → $i_d=\beta(V_{GS}-V_T)v_{gs}+\frac{\beta}{2}v_{gs}^2\approx g_mv_{gs}$（2次の項を無視）。
$e^x$$\sin x$$\cos x$$\frac{1}{1-x}$$(1+x)^\alpha$$\log(1+x)$
1次$1+x$$x$$1$$1+x$$1+\alpha x$$x$
2次$1+x+\frac{x^2}{2}$$x$$1-\frac{x^2}{2}$$1+x+x^2$$+\frac{\alpha(\alpha-1)}{2}x^2$$x-\frac{x^2}{2}$
  • 前提：$x\ll1$。1次近似 $f(x)\cong f(a)+f'(a)(x-a)$（接線）。テイラー $f(x)=f(a)+\sum\frac{f^{(k)}(a)}{k!}(x-a)^k$、マクローリン＝$a=0$。収束半径 $|x|\lt r$。
  • オイラーの証明：$e^{ix}$ を展開 → 実部 $1-\frac{x^2}{2!}+\cdots=\cos x$、虚部 $x-\frac{x^3}{3!}+\cdots=\sin x$。
  • 内積 $(a,b)=a^Tb$、$=0$ で直交。正規直交系 $(u_i,u_j)=\delta_{ij}$ → 基底。シュワルツ $|(a,b)|\le|a||b|$。
  • 関数の内積 $\int_0^Tfg\,dx$。$\int_0^{2\pi}\cos mx\cos nx\,dx=\pi\delta_{mn}$（積和公式 $\frac12\{\cos(m+n)x+\cos(m-n)x\}$）→ 三角関数は直交する関数の基底。
  • フーリエ級数 $f=\frac{a_0}{2}+\sum(a_n\cos n\omega t+b_n\sin n\omega t)$、$a_n=\frac{2}{T}\int_0^Tf\cos n\omega t\,dt$（係数＝内積）。複素：$c_n=\frac1T\int f e^{-jn\omega t}dt$。$T\to\infty$ でフーリエ変換 $F(\omega)=\int f e^{-j\omega t}dt$。
  • ラプラス：$\int|f|dt\lt \infty$ でないとフーリエ不可 → $e^{-\gamma t}$ を掛けて収束 → $F(s)=\int_0^\infty fe^{-st}dt$、$s=\gamma+j\omega$。

⑤ 小信号等価回路（第5回）

  • $V_T$ 以下は弱反転（電流は指数関数）。アナログ増幅は飽和領域（$g_m$ 大・$r_0$ 大 → $g_mr_0$ 大。線形に入ると増幅率が極端に低下）。
  • バイアス電流が大きいほど $g_m$ 大。直流成分には情報がない → 信号成分 $i_d$ だけ扱う。
  • 等価回路：ゲートは開放。D–S 間に 電流源 $g_mv_{gs}$ ‖ $r_0$ ‖ 電流源 $-g_{mb}v_s$
    $i_d=g_mv_{gs}+\frac{v_d-v_s}{r_0}-g_{mb}v_s$
  • $g_m\approx\sqrt{2\beta I_D}$（スライドの $\sqrt{\beta I_D}$ は誤記）／$g_{mb}=g_m\eta$（$\eta=\partial V_T/\partial V_S=0.1\sim0.2$、ソース↑→$V_T$↑→電流↓）／$r_0=[dI_D/dV_{DS}]^{-1}\approx\frac{1}{\lambda I_D}$
  • $g_m$, $r_0$ はバイアス電流 $I_D$ の関数（動作中心を決めると $I_D$ が決まる）。小信号の抵抗＝微分抵抗：電流が多くても傾きが寝ていれば抵抗は高い。
  • 定電流負荷：入力↑→電流が $g_mv_{in}$ 増えようとする→電流源で固定→$V_{DS}$ が下がる。特性が寝ているので大きな電圧変化。真性利得 $v_{out}/v_{in}=-g_mr_0$（MOS 1個の最大）。
  • 一般解 $A_V=G_mR_{out}$（$G_m$：回路の変換係数、$g_m$：素子）。MOS は電圧→電流の変換役。
  • 一般式：$i_d=g_mv_g-\left(g_m^*+\frac{1}{r_0}\right)v_s+\frac{1}{r_0}v_d$

⑥ 接地増幅回路（第6回）

STEP：0 一般式／1 入力端子だけ残し他は0 → $G_m$／3 出力端子だけ残す → 素子の抵抗／4 回路から $R_{out}$／5 $A_v=\pm G_mR_{out}$（符号＝「入力↑で出力↑か↓か」）。小信号では $V_{DD}$＝GND、固定電位も0。

  • 逆相（ソース接地）：入力↑→電流↑→負荷の降下↑→出力↓。SF 同相：入力↑→電流↑→$R_L$ の電圧↑→出力↑。ゲート接地 同相：ソース↑→$V_{GS}$↓→電流↓→出力↑。
  • PMOS 負荷（ゲート固定＝定電流源）：$A_v=-g_{m1}(r_{01}/\!/r_{02})=-\frac{\sqrt{2\beta_1}}{(\lambda_1+\lambda_2)\sqrt{I_D}}$ → 電流↑で利得↓（$g_m\propto\sqrt{I_D}$、$r_0\propto1/I_D$）。
  • SF レベルシフト：$V_{out}=V_{in}-V_T-\sqrt{2I/\beta}$（$V_T$ の基板効果に注意）。CMOS イメージセンサ画素の SF＝バッファ（列線の電流源が負荷）。
  • 利得を上げる：ソース接地は 30dB 程度（講師の定義 $10\log_{10}$ で1000倍）で OPアンプには不足。$g_m$↑は面積（W/L）と電流が増えて不利 → $R_{out}$ を MOS で大きく見せる。
  • 抵抗変換（ゲート固定 MOS）：ドレイン側から $(g_m^*r_0+1)R_S$（拡大）、ソース側から $\frac{R_L}{g_m^*r_0}+\frac{1}{g_m^*}$（縮小）。
  • カスコード（cascaded triode）：$R_S$ だと電流が稼げない → 入力 MOS の上にゲート固定 MOS を積む。
    $A_V=-g_{m1}\left[(g_{m2}^*r_{o2}+1)r_{o1}/\!/(g_{m3}^*r_{o3}+1)r_{o4}\right]$（従来 $-g_{m1}[r_{o1}/\!/r_{o4}]$ の約 $g_mr_o$ 倍）
