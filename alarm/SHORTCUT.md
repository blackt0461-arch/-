# iPhoneショートカット「目覚まし同期」の作り方（24時間方式）

`alarms.json` を読み込んで、**今から24時間以内に鳴る予定**を時計アプリのアラームに反映するショートカットです。
当日の予定（例：今日の12:00）も、翌朝の予定も同じ仕組みで扱います。iOS 27 で確認した操作名で書いています。

## 仕組み
1. 今日の日付の `schedule` を読む。その中の `candidates` に、今日と明日のアラームが鳴る日時（`at`）付きで入っている
2. 鳴る日時が「今」より後、かつ「今＋1日」より前のものだけを残す
3. ラベルに `⏰auto` を含むアラームのうち、残したものはオン、それ以外はオフにする
4. 残したもので、まだ時計アプリにないものは作る

触るのは、ラベルに `⏰auto` を含むアラームだけです。自動実行では「削除」は使いません（毎回確認が出て止まるため）。

## 操作のコツ
- **変数を入れる**：欄をタップすると、キーボードの上に変数の候補が出る。目的のものがなければ、欄を長押し →「変数を選択」→ 該当するアクションをタップする
- **辞書の欄**は、直前の結果が自動で入ることが多い。必ず指定どおりに選び直す
- **if文の条件に目的の選択肢が出ない**ときは、左側の変数をタップして「型」を変える（日付やテキスト）
- **アラームを切り替える**の「›」→「実行時に表示」はオフにする
- **アラームを検索**のフィルタは指定した数だけにする。空のフィルタが残っていると正しく検索できない

## 組み立て

### パート1：データを取得する
1. **URLの内容を取得**
   - URL：`https://api.github.com/repos/blackt0461-arch/alarm-data/contents/alarms.json`
   - 「›」→ 方法 **GET** → ヘッダを2つ
     - `Authorization` ／ `Bearer github_pat_…`（Bearerのあとに半角スペース。iPhone用の読み取り専用トークン）
     - `Accept` ／ `application/vnd.github.raw+json`

### パート2：今日の日付
2. **日付**（「現在の日付」と表示される）
3. **日付をフォーマット** → 日付の書式 **カスタム** → `yyyy-MM-dd`
4. **変数を設定** → `対象日`

### パート3：今日の予定を取り出す
5. **辞書の値を取得** → キー `schedule`、辞書＝1の **URLの内容**
6. **辞書の値を取得** → キー＝変数 **`対象日`**（辞書は5の結果）
7. **変数を設定** → `予定`
8. **if文** → `予定` ／ **値がない**
   - **通知を表示**：「目覚まし：予定データを取得できませんでした」
   - **このショートカットを停止**
   - （その他の場合は空）
9. **辞書の値を取得** → キー `candidates`、辞書＝**`予定`**
10. **変数を設定** → `候補`

### パート4：24時間以内のものを選ぶ
11. **日付**（現在の日付）
12. **変数を設定** → `今`
13. **日付を調整** → `今` に **1 日** を **追加**
14. **変数を設定** → `期限`
15. **各項目を繰り返す** → 入力＝**`候補`**
    - **辞書の値を取得** → キー `at`、辞書＝**繰り返し項目**
    - **変数を設定** → `鳴る日時`
    - **if文** → `鳴る日時` ／ **が次より後** ／ `今`（選択肢がなければ `鳴る日時` の型を **日付** に）
      - **if文** → `鳴る日時` ／ **が次より前** ／ `期限`
        - **変数に追加** → **繰り返し項目** を `予定リスト` に追加
        - **辞書の値を取得** → キー `label`、辞書＝**繰り返し項目**
        - **変数に追加** → その結果を `ラベルたち` に追加
      - （内側のその他の場合は空）／If文の終了
    - （外側のその他の場合は空）／If文の終了
    - 繰り返しの終了
16. **テキストを結合** → 入力＝`ラベルたち`、区切り＝**改行**
17. **変数を設定** → `ラベル一覧`

### パート5：⏰auto アラームをオン／オフする
18. **アラームを検索** → フィルタは1つだけ：**ラベル ／ が次を含む ／ `⏰auto`**
19. **各項目を繰り返す** → 入力＝18の **アラーム**
    - **if文** → `ラベル一覧`（型＝テキスト）／ **が次を含む** ／ 繰り返し項目 → **ラベル**
      - **アラームを切り替える** → 繰り返し項目 を **オン**（実行時に表示：オフ）
    - その他の場合
      - **アラームを切り替える** → 繰り返し項目 を **オフ**（実行時に表示：オフ）
    - If文の終了
    - 繰り返しの終了

### パート6：足りないアラームを作る
20. **各項目を繰り返す** → 入力＝**`予定リスト`**
    - **辞書の値を取得** → キー `label`、辞書＝**繰り返し項目** → **変数を設定** `ラベル`
    - **辞書の値を取得** → キー `ampm`、辞書＝**繰り返し項目** → **変数を設定** `時刻`
    - **アラームを検索** → フィルタは1つだけ：**ラベル ／ が次と等しい ／ `ラベル`**
    - **if文** → その検索結果の **アラーム** ／ **値がない**
      - **アラームを追加** → 時刻＝`時刻`、名称＝`ラベル`（繰り返しは空のまま）
    - その他の場合（空）／If文の終了
    - 繰り返しの終了

## テスト
- 今日このあとに予定がある状態で ▶︎ を実行し、時計アプリに `⏰auto …` が**正しい時刻・オン**でできていることを確認する
- もう一度実行して、同じアラームが**増えない**ことを確認する
- Web画面かチャットでその予定を「鳴らさない」にして実行し、**オフ**になることを確認する

## 自動実行（オートメーション）
「オートメーション」タブで、各オートメーションの実行するショートカットを「目覚まし同期」にする。

| きっかけ | 設定 |
|---|---|
| 充電器 → 接続されている | すぐに実行・実行時に通知オフ |
| 時刻 → 22:00 毎日 | 同上 |
| （任意）アプリを開いたとき（LINEなど、よく開くアプリ） | 同上。同期の回数が増えて、変更の反映が早くなる |

## お掃除（たまに手動で）
使い終わった `⏰auto` アラームはオフのまま残る。時計アプリの「編集」から消してよい。次の同期で、必要な分は作り直される。
