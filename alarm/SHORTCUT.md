# iPhoneショートカット「目覚まし同期」の作り方

`alarms.json` を読み込んで、時計アプリのアラームを「次の朝」の予定に合わせるショートカットです。
iOS 27.0.1 の実機で組み立てながら確認した手順です。

## 安全のためのルール
- 触るのは、ラベルに **`⏰auto`** を含むアラームだけ（自分で作ったアラームには触らない）
- 使うのは「検索」「追加」「切り替える」だけ。「削除」は毎回確認が出て自動実行が止まるため、使わない
- 通信に失敗しても、ショートカットはエラーで止まらず、エラーの内容（JSON）を受け取って先に進む。その場合は `schedule` が取れないので、手順11で停止し、アラームは変わらない

## 実機で分かったこと
| 内容 | 結果 |
|---|---|
| アラームを追加・検索・切り替える | 確認なしで動く（「›」の「実行時に表示」はオフにする） |
| アラームを削除 | 毎回確認が出る → 自動実行では使わない |
| 時刻を `3:33` で指定 | 15:33になった → `6:30 AM` 形式（`ampm`）を使う |
| 検索の条件 | 「が次で始まる」はなく、「が次を含む」「が次と等しい」だけ |
| 繰り返しに変数を指定 | 入力はできるが、`水`／`水曜日` のどちらも反映されない → 繰り返しは使わない |
| 401 Bad credentials | Authorization ヘッダにトークンが入っていなかった |
| 404 Not Found | トークンなしで非公開リポジトリにアクセスした |

## 事前準備
Fine-grained token を作る（Repository access：`alarm-data` のみ、Contents：**Read-only**）

## 組み立て（上から順に追加）

**データを取得する**
1. **URLの内容を取得**：`https://api.github.com/repos/blackt0461-arch/alarm-data/contents/alarms.json`
   - 「›」→ ヘッダを2つ追加
     - `Authorization` ＝ `Bearer github_pat_…`（Bearerのあとに半角スペース、トークンを直接書く）
     - `Accept` ＝ `application/vnd.github.raw+json`

**対象日を作る**
2. **日付**（「現在の日付」と表示される）
3. **日付を調整**：**減算** 4 時間
4. **日付を調整**：**追加** 1 日（入力は3の「調整済みの日付」）
5. **日付をフォーマット**：日付の書式 **カスタム** → `yyyy-MM-dd`（入力は4の「調整済みの日付」）
6. **変数を設定**：`対象日`

**予定を取り出す**
7. **辞書の値を取得**：キー `schedule`、辞書 ＝ 1の「URLの内容」
8. **辞書の値を取得**：キー ＝ 変数 `対象日`
9. **変数を設定**：`予定`
10. **if文**：`予定` が **値がない**
    - （任意）**通知を表示**「目覚まし：予定データを取得できませんでした」
    - **このショートカットを停止**
    - その他の場合（空）／If文の終了
11. **辞書の値を取得** `scope`（辞書＝`予定`）→ **変数を設定** `スコープ`
12. **辞書の値を取得** `labels`（辞書＝`予定`）→ **変数を設定** `ラベル一覧`
13. **辞書の値を取得** `alarms`（辞書＝`予定`）→ **変数を設定** `アラーム一覧`

**いまある ⏰auto アラームをオン／オフする**
14. **アラームを検索**：「次の**いずれか**に当てはまる」
    - ラベル ／ が次を含む ／ `スコープ`
    - ラベル ／ が次を含む ／ `⏰auto 単発 `
15. **各項目を繰り返す**（入力は14の「アラーム」）
    - **if文**：`ラベル一覧`（タップして型を **テキスト** にする）／ が次を含む ／ 繰り返し項目 → **ラベル**
      - **アラームを切り替える**：繰り返し項目 を **オン**（実行時に表示：オフ）
    - その他の場合
      - **アラームを切り替える**：繰り返し項目 を **オフ**（実行時に表示：オフ）
    - If文の終了
    - 繰り返しの終了

**足りないアラームを作る**
16. **各項目を繰り返す**（入力は変数 `アラーム一覧`）
    - **辞書の値を取得** `label`（辞書＝**繰り返し項目**）→ **変数を設定** `ラベル`
    - **辞書の値を取得** `ampm`（辞書＝**繰り返し項目**）→ **変数を設定** `時刻`
    - **アラームを検索**：ラベル ／ が次と等しい ／ `ラベル`
    - **if文**：その「アラーム」が **値がない**
      - **アラームを追加**：時刻＝`時刻`、名称＝`ラベル`（繰り返しは空のまま）
    - その他の場合（空）／If文の終了
    - 繰り返しの終了

## テストのしかた
- 手順4を一時的に「**5** 日」などにすると、アラームがある日を対象にできる。**終わったら必ず「1」に戻す**
- 2回実行しても同じアラームが増えないこと
- Web画面で例外（鳴らさない）を設定して実行し、オフになること

## 自動実行（オートメーション）
| きっかけ | 設定 |
|---|---|
| 充電器 → 接続されている | すぐに実行・実行時に通知オフ → 目覚まし同期 |
| 時刻 → 22:00 毎日 | 同上 |

## お掃除（たまに手動で）
時刻を変えると、古い `⏰auto` アラームがオフのまま残る。時計アプリの「編集」から手で消すか、
「アラームを検索（ラベル が次を含む `⏰auto`）→ アラームを削除」の手動ショートカットを使う（確認ダイアログはタップする）。
消しすぎても、「目覚まし同期」を実行すれば次の朝の分は作り直される。
