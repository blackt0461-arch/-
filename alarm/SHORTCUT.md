# iPhoneショートカットの作り方

`alarms.json` を読んで、標準の時計アプリのアラームを「次の朝」の予定に合わせるショートカットです。
動作確認は iOS 27.0.1 で行いました。

## 安全のためのルール

- 触るのは、ラベルが **`⏰auto`** で始まるアラームだけです。自分で作ったアラームには触りません。
- 使うのは「検索」「追加」「切り替える」だけです。「削除」は確認が必要で自動実行が止まるため、使いません。
- 取得に失敗したら、ショートカットはその場でエラーで止まります。アラームは何も変わりません（前回の状態のまま鳴ります）。

## 事前準備：読み取り専用トークン

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token

- Repository access: **Only select repositories → `alarm-data`**
- Permissions → Repository permissions → **Contents: Read-only**
- 有効期限は好みで設定します（切れると同期が止まるので、カレンダーにメモしておきましょう）。

Web画面用には、**Contents: Read and write** のトークンを別に作ります。

## ショートカット「目覚まし同期」

「ショートカット」アプリで **＋** をタップし、名前を「目覚まし同期」にして、上から順にアクションを追加します。
（ ）内は検索するアクション名です。

### 1. データを取得する
1. （**テキスト**）読み取り専用トークンを貼り付ける
2. （**URLの内容を取得**）
   - URL: `https://api.github.com/repos/blackt0461-arch/alarm-data/contents/alarms.json`
   - 「›」を開いて **ヘッダ** を2つ追加する
     - `Authorization` ＝ `Bearer ` ＋ 1.の「テキスト」変数（Bearer のあとに半角スペース）
     - `Accept` ＝ `application/vnd.github.raw+json`

### 2. 「次の朝」の日付を作る
3. （**現在の日付**）
4. （**日付を調整**）**減算 4 時間**
5. （**日付を調整**）**加算 1 日**
6. （**日付をフォーマット**）日付フォーマット：**カスタム** → `yyyy-MM-dd`
7. （**変数を設定**）名前 `対象日`

> 4時間を引くのは、深夜（0〜4時）に同期したときに「今日の朝」を対象にするためです。
> 22時なら翌日、午前1時ならその日、朝7時なら翌日が対象になります。

### 3. その日の予定を取り出す
8. （**辞書の値を取得**）キー `schedule`、辞書 ＝ 2.の「URLの内容」
9. （**辞書の値を取得**）キー ＝ 変数 `対象日`、辞書 ＝ 8.の結果
10. （**変数を設定**）名前 `予定`
11. （**if**）`予定` が **値がない**
    - （**通知を表示**）「目覚まし：予定データが期限切れです。Webで一度保存してください」
    - （**ショートカットを停止**）
    - （終了if）
12. （**辞書の値を取得**）キー `scope`、辞書 `予定` → （**変数を設定**）`スコープ`
13. （**辞書の値を取得**）キー `labels`、辞書 `予定` → （**変数を設定**）`ラベル一覧`
14. （**辞書の値を取得**）キー `alarms`、辞書 `予定` → （**変数を設定**）`アラーム一覧`

### 4. いまある ⏰auto アラームをオン／オフする
15. （**アラームを検索**）
    - 一番上の「すべて」を **「いずれか」** に変える
    - フィルタ1：**ラベル** ／ **次で始まる** ／ 変数 `スコープ`
    - フィルタ2：**ラベル** ／ **次で始まる** ／ `⏰auto 単発 `（最後に半角スペース）
16. （**各項目を反復**）15.の結果
    - （**if**）`ラベル一覧` が **次を含む** → 値に「繰り返し項目」を入れて、タップして **ラベル** を選ぶ
      - （**アラームを切り替える**）繰り返し項目 を **オン** に変更 ／ 「›」で **実行時に表示をオフ**
    - （**その他の場合**）
      - （**アラームを切り替える**）繰り返し項目 を **オフ** に変更 ／ **実行時に表示をオフ**
    - （終了if）
    - （反復の終了）

### 5. 足りないアラームを作る
17. （**各項目を反復**）変数 `アラーム一覧`
    - （**辞書の値を取得**）キー `label`、辞書 ＝ 繰り返し項目 → （**変数を設定**）`ラベル`
    - （**辞書の値を取得**）キー `ampm` → （**変数を設定**）`時刻`
    - （**辞書の値を取得**）キー `repeat` → （**変数を設定**）`曜日`
    - （**アラームを検索**）ラベル ／ **次と等しい** ／ 変数 `ラベル`
    - （**項目数を取得**）
    - （**if**）項目数 **＝ 0**
      - （**アラームを追加**）時刻 ＝ 変数 `時刻`、名称 ＝ 変数 `ラベル`
        - 「›」を開き、**繰り返し** があれば：`曜日` に値があるときはその曜日を選ぶ
          （曜日ごとの基本パターンは、毎週繰り返すアラームにしておくと、同期できない日があっても鳴り続けます）
      - （終了if）
    - （反復の終了）

> **時刻の注意：** `time`（`06:30`）ではなく、必ず `ampm`（`6:30 AM`）を使ってください。
> テストで「3:33」が15:33として作られたため、午前／午後を明示しています。

### 6. 動作テスト
- ▶︎で実行し、時計アプリに `⏰auto 金 06:30` のようなアラームができて、正しい時刻（午前）でオンになっていることを確認します。
- もう一度実行しても、アラームが**増えない**ことを確認します。

## 自動で実行する（オートメーション）

「ショートカット」アプリ → 下の **オートメーション** → **＋**

| きっかけ | 設定 |
|---|---|
| **充電器** → 「接続されている」 | 「すぐに実行」・「実行時に通知」オフ → 「目覚まし同期」 |
| **時刻** → 22:00 毎日 | 同上 |

手動で実行したいときは、「目覚まし同期」をホーム画面やウィジェットに追加しておきます。

## ショートカット「目覚ましお掃除」（たまに手動で）

時刻を変えると、古い `⏰auto` アラームがオフのまま残ります。たまってきたら実行します。

1. （**アラームを検索**）ラベル ／ 次で始まる ／ `⏰auto`、さらに **有効 ／ オフ**（この条件が選べる場合）
2. （**アラームを削除**）→ 確認が出たら「削除」をタップ

※「有効」で絞り込めない場合は、オンのものも消えてしまいます。お掃除のあとは「目覚まし同期」を1回実行すれば元に戻ります。
