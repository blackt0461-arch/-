# 電波チェッカー(引き継ぎ資料)

iPhone 向けの PWA です。アプリを開いている間、通信の応答時間を測ります。電波が悪くなると画面の色とアラーム音で知らせます。

## 決まっている仕様

| 項目 | 内容 |
|---|---|
| 対象端末 | iPhone(Safari/ホーム画面に追加して使う) |
| 形式 | PWA(無料。Mac・Apple開発者登録は使わない) |
| 動作 | アプリを開いている間だけ。他のアプリを開くと止まる(iOSの制約として了承済み) |
| 判定方法 | 3秒ごとに `ping.txt` を取得して応答時間を測る(iPhoneは電波強度をアプリから読めないため) |
| 「遅い」 | 応答が1秒を超えるのが3回連続 |
| 「圏外」 | 通信失敗(3秒でタイムアウト)が2回連続、または端末がオフラインを通知 |
| 「回復」 | 正常な応答が3回連続 |
| 知らせ方 | 画面の色(緑=良好/黄=遅い/赤点滅=圏外)+アラーム音。回復時は別の音 |
| 速さの表示 | 直近3回の応答時間の中央値を、アンテナ4本と言葉で表示。〜200ms=速い(動画・通話も快適)/〜500ms=普通(SNS・LINEは快適)/〜1000ms=やや遅い(読み込みに少し待つ)/それ以上=遅い(途切れやすい)。`app.js` の `LEVELS` で変更できる |
| 画面構成 | 上にアンテナと速さ、中央に グラフ/マップ/記録 のタブ、下端に親指で押せる開始・停止ボタン。補足の説明文は置かない方針 |
| 追加機能 | 画面を点けたままにする(Wake Lock)、直近5分の応答時間グラフ、悪かった時刻の記録(端末内に保存)、回復時の通知音 |

| 電波マップ | 「位置情報を記録する」をオンにすると、測定結果を位置と一緒に保存する。25m動くごと、または良好/遅い/圏外が変わった時に1点。表示は「周辺(半径500m)」と「全体」を切り替えられる。地図画像は使わず、記録した点を自前で描く |
| 圏外の予告 | 過去に遅い/圏外だった地点の200m以内に近づくと、青いバナーと予告音で知らせる。5分間は繰り返さない。直近10分の記録は使わない(通り過ぎたばかりの場所で鳴らないように) |

判定の数値は `app.js` 先頭の `CONFIG` で、マップと予告の数値は `map.js` 先頭の `MCFG` で変えられます。

位置情報はこのiPhoneの localStorage だけに保存し、外部には送りません(最大3000点)。屋内ではGPSの誤差が大きく、部屋ごとの区別はできません。

## デバッグ済みの不具合

- 他のアプリから戻ったり、開始/停止を連打したりすると、測定が二重三重に走っていた → 世代番号で常に1本だけにした
- サービスワーカーがキャッシュ優先だったので、修正版を公開しても古い画面が残っていた → ネット優先にし、つながらない時だけキャッシュを使うようにした
- 他のアプリから戻った後に音が鳴らないことがある(iOS) → 画面に触れたら音を復帰するようにした
- サービスワーカーが使えない環境で例外が出る可能性があった → try/catch で無視するようにした

## ファイル構成

- `index.html` / `style.css` / `app.js`:アプリ本体
- `map.js`:電波マップと圏外の予告
- `sw.js`:オフラインでも画面を開けるようにするサービスワーカー。`ping.txt` はキャッシュしない
- `manifest.webmanifest`、`icons/`:ホーム画面に追加するための設定とアイコン
- `ping.txt`:応答時間の測定に使う小さなファイル。必ず同じ場所に置くこと

## 引き継ぎ先でやること

1. HTTPS の静的ホスティングに、このフォルダをそのまま公開する(GitHub Pages、Netlify、Cloudflare Pages など。公開先はまだ決めていない)。ビルドは不要
2. iPhone の Safari で公開URLを開く →「共有」→「ホーム画面に追加」
3. ホーム画面のアイコンから開き、「監視を開始」をタップする(iPhoneは、タップしないと音を鳴らせない)

## 注意点(iOSの制約)

- バイブレーションは使えない。マナーモード中は音が鳴らないことがある
- 画面を点けたままにする機能は iOS 18.4 以降のホーム画面アプリで動く。古いiOSでは、画面が自動で消えると監視が止まる
- 測定先は公開したサーバーなので、サーバー自体が遅いと「遅い」と判定されることがある
- 画面の確認はPCのヘッドレスChromeで行った(良好→圏外→回復の切り替え、記録、移動を模擬したマップ記録と予告)。実機のiPhoneではまだ試していない
- claude.ai のアーティファクトでプレビューすると、位置情報とサービスワーカーは使えない(マップは「デモ」ボタンで確認できる)
