# LYRIC BOOK 仕様

歌詞（実在する曲・自作）と歌い方を整理する、自分専用のノートアプリ。
公開先：https://blackt0461-arch.github.io/-/lyric-book/

## 1. 使う人・端末
- 使うのは本人だけ。スマホとiPadで同じデータを見る。
- ログインはユーザー名とパスワード。登録したときに「復活用の合言葉」を出し、パスワードを忘れたら合言葉で作り直せる。
- 「ためしに使う」を押すと、ログインなしでこの端末の中だけに保存して試せる。

## 2. 保存先
- Supabase（ROOMIN と同じプロジェクト）。表の名前は `lb_` で始める。
- 表には直接さわらず、`supabase/setup.sql` の関数（`lb_...`）だけを呼ぶ。
- 録音は声向けの軽い形（約32kbps）で保存する。1分で約0.25MB。
- 歌手の写真は小さくして保存する。

## 3. 画面
- ホーム：上の帯で「実在する曲」「自作」を切りかえる。検索欄（曲名・歌手・よみがな・歌詞）。
  - 実在する曲：歌手の写真が並ぶ。写真がなければ iTunes から代表的なアルバムのジャケットを自動で入れる（あとでスクショなどに変えられる）。
  - 自作：テーマ（恋愛・人生・家族・失恋。設定で足したり変えたりできる）の色で分ける。新しく直した順。
- 歌手の画面：上の部分の色がジャケットの色に合わせて変わる。曲はあいうえお順（よみがなを使う）。
- 歌詞ページ：曲名を色の帯に。作成日時・更新日時。キー（原キー・自分のキー・最高音・最低音・歌い出し、音は ▶ で鳴らせる）。パートごとの歌詞。録音の一覧。
  - 歌詞の文字をなぞって選ぶと、下に記号・色・メモのボタンが出る。同じものをもう一度押すと消える。
  - 録音は何個でもできる。長押しで「上書きして録り直す・名前を変える・消す」。
- 編集：曲名・歌手・よみがな・テーマ・キー・歌詞。歌詞は `[サビ]` のような行でパートを分ける（ボタンで入れられる）。写真の歌詞は iPhone/iPad の文字読み取りで写して貼る（やり方を案内する）。
- 鍵盤：ピアノの鍵盤で好きな音を鳴らせる。
- 解説：記号と色の意味、音の高さ（lowG〜hihiA）を一覧で。どれも ▶ で鳴らせる。
- 設定：夜用の暗い画面、テーマ・記号・色の追加と変更、自分の最高音、ログアウト。

## 4. 歌い方の記号（はじめから入っているもの）
V ブレス／裏 裏声／ミ ミックスボイス／ガ がなり／〜 ビブラート／↗ しゃくり／↘ フォール／こ こぶし
色：強く（赤茶）／やさしく（青緑）

## 5. 音の高さの呼び方
カラオケの呼び方。hiA＝ラ（440Hz）。A から上がるごとに low → mid1 → mid2 → hi → hihi と変わる。

## 6. 見た目
- 茶色が基本。文字も黒ではなく茶色。
- 字体は教科書のような「Klee One」。ロゴだけ Cormorant Garamond。歌詞の上の記号はシンプルな字体。
- 画面ごとに雰囲気を変える：ホーム＝こげ茶の帯、歌手＝ジャケットの色、歌詞＝紙、解説＝クラフト紙。
