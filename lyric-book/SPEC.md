# LYRIC BOOK 仕様

歌詞（実在する曲・自作）と歌い方を整理する、自分専用のノートアプリ。
公開先：https://blackt0461-arch.github.io/-/lyric-book/

## 1. 使う人・端末
- 使うのは本人だけ。スマホとiPadで同じデータを見る。
- ログインはユーザー名とパスワード（スマホとiPadで同じものを見る）。登録したときに「復活用の合言葉」を出し、パスワードを忘れたら合言葉で作り直せる。
- アプリの中には、Googleに貼るコードは出さない（コードは server/Code.gs。貼りかえが必要なときは、作る人がチャットで渡す）。

## 2. 保存先（グーグルドライブだけ）
- データはすべて、本人のグーグルドライブの「LYRIC BOOK」フォルダに置く。Supabase は使わない。
- 受け口は Google Apps Script 1本（`server/Code.gs`）。本人が script.google.com に貼って、ウェブアプリとして公開する（1回だけ）。そのURLを `js/cloud.js` の `SCRIPT_URL` に書く。
- 登録できるのは1人だけ（最初に登録した人）。ログインを10回まちがえると10分止める。
- フォルダの中：
  - 「データ（さわらないでください）.json」：歌詞・歌手・設定・録音の一覧
  - 「録音」フォルダ：録音のファイル。消した録音は「録音/消した録音」に移して残す
  - 「LYRIC BOOK 最新.json」「歌詞まとめ.txt」「日ごと」（1日1つ、30日分）：10分ごとに、変わっていたら作る
- 設定 →「戻す」でバックアップのファイルを選ぶと、今のデータを消さずに戻す（ない曲は足す、中身がちがう曲は「（バックアップの版）」として残す）。
- 録音は声向けの軽い形（約32kbps）。歌手の写真は小さくして保存する。

## 2-3. 端末の中のデータ・電波がないとき
- 読みこんだデータは端末の中にも残す（録音の音は除く）。電波がないときは前回のデータで開く。
- 電波がないときに直したものは、ためておいて、つながったら送る。
- 同じ曲を別の端末でも直していたら、新しいほうをその曲にして、この端末の版は「（別の端末の版）」という曲で残す。

## 3. 画面
- ホーム：上の帯で「実在する曲」「自作」を切りかえる。検索欄（曲名・歌手・よみがな・歌詞）。
  - 実在する曲：歌手の写真が並ぶ。写真がなければ iTunes から代表的なアルバムのジャケットを自動で入れる（あとでスクショなどに変えられる）。
  - 自作：テーマ（恋愛・人生・家族・失恋。設定で足したり変えたりできる）の色で分ける。新しく直した順。
- 歌手の画面：上の部分の色がジャケットの色に合わせて変わる。曲はあいうえお順（よみがなを使う）。
- 歌詞ページ：曲名を色の帯に。作成日時・更新日時。キー（原キー・自分のキー・最高音・最低音・歌い出し、音は ▶ で鳴らせる）。パートごとの歌詞。録音の一覧。
  - 歌詞の文字をなぞって選ぶと、下に記号・色・メモのボタンが出る。同じものをもう一度押すと消える。
  - 録音は何個でもできる。長押しで「上書きして録り直す・名前を変える・消す」。
- 編集：曲名・歌手・よみがな・テーマ・キー・歌詞。歌詞は `[サビ]` のような行でパートを分ける（ボタンで入れられる）。写真の歌詞は iPhone/iPad の文字読み取りで写して貼る（やり方を案内する）。
- 鍵盤：ピアノの鍵盤で好きな音を鳴らせる。
- 解説：記号と色の意味、音の高さ（lowG〜hihiA）を一覧で。どれも ▶ で鳴らせる。
- 設定：夜用の暗い画面、テーマ・記号・色の追加と変更、自分の最高音、ログアウト。

## 4. 歌い方の記号（はじめから入っているもの）
V ブレス／裏 裏声／ミ ミックスボイス／ガ がなり／〜 ビブラート／↗ しゃくり／↘ フォール／こ こぶし
色：強く（赤茶）／やさしく（青緑）

## 5. 音の高さの呼び方
カラオケの呼び方。hiA＝ラ（440Hz）。A から上がるごとに low → mid1 → mid2 → hi → hihi と変わる。

## 6. 見た目
- 茶色が基本。文字も黒ではなく茶色。
- 字体は教科書のような「Klee One」。ロゴだけ Cormorant Garamond。歌詞の上の記号はシンプルな字体。
- 画面ごとに雰囲気を変える：ホーム＝こげ茶の帯、歌手＝ジャケットの色、歌詞＝紙、解説＝クラフト紙。

## 7. 2.0 で足したもの
- 保存中は上のまん中に「保存中…」「保存しました」を出す。
- 原キーとテンポは、Apple の公式の試聴（30秒）をアプリが聞いて推定する（「推定」と出る）。最高音・最低音・歌い出しは自動では出せないので「測定不能」と出し、「音程チェック」か鍵盤で入れる。
- 音程チェック：マイクで声の高さを出す。いちばん高い・低い音を、曲の最高音・最低音や「自分の最高音・最低音」に入れられる。
- 音を選ぶのは鍵盤から。▶ は自分のキー（上げ下げしたぶん）で鳴る。
- 本番モード：テンポと「1行に使う小節」（はじめは2小節）で歌詞が自動で進む。速く・遅く、行をタップでそこへ。「[間奏 8]」のように書いたパートは、その小節ぶん「♪ 間奏」を出して待つ。画面が暗くなりにくくする。
- 練習の印（練習中・歌える・十八番）と点数の記録。ホームで印ごとに絞りこめる。
- セットリスト：曲を順番に並べ、本番モードで続けて通す。
- 録音：再生中は下に小さな再生バーを出し、歌詞を見ながら聞ける。電波がないときは端末に残して、つながったら送る。
- 歌手の写真：その歌手を特定してから、その人のアルバムのジャケットを探す。写真はいくつでも足せて、★の1枚がホームに出る。ほかは歌手の画面の上で自動で流れる。
- 歌詞を書き直しても、変わっていない文字についた記号・色は残す（文字を1つずつ照らし合わせる）。
- 編集：行ごとの文字数、前の版（20個）に戻す。
- 消した曲・歌手は「最近消した曲」に30日残し、そのあと本当に消す。
- 曲ごとに「メンバーに見せる」。メンバーのホームの「みんなの曲」に出て、見るだけ・自分のノートにコピーできる。
- 解説：パートの説明（Aメロとは等）を追加し、使い方を見出し・番号・色で見やすくした。
- 受け口（server/Code.gs）は版3：みんなの曲（lb_shared）と試聴の取りよせ（lb_preview）を追加。

## 8. 2.1・2.2 で足したもの（GitHub に送れず、ZIP で受け渡し）
- 2.1：開いたらすぐ、端末の前回のデータで画面を出し、Googleとのやりとりは裏で。一度聞いた録音・録った録音は端末にとっておく。
- 2.2：音が鳴らないことがある問題を直した（最初のタップで音の準備、消音スイッチでも鳴るように、マイクを使ったあとやアプリを戻したときは作りなおす）。
- 2.2：ホームに自分のタブを足せる（例：バンド）。名前変更・消すは設定から。曲は「…」→「タブに入れる・はずす」、編集画面のタブのボタン、タブの画面の右下「＋」から入れる。1曲を複数のタブに入れられる。
- 2.2：歌手の画面の「この歌手の曲から選んで入れる」で、その歌手の曲（iTunes）をリリース年・ジャケットつきで一覧にして、タップで入れる。ライブ版・伴奏版などは元の曲名にまとめる。
- 2.2：曲のリリース年を表示（曲ページ・一覧）。
- 2.2：編集画面の「保存する」を下の大きいボタンに、「この曲を消す」を右上の小さいボタンに入れ替えた。
- 2.2：色とは別に「線（まっすぐ）」「波線」の2種類を引ける。同じ文字に色と線を重ねられる。
- まだ：許可をもらったサイトから、歌詞・原キー・最高音・最低音・歌い出しを取ってくる部分（本人からサイト名をもらってから作る）。
- 2.3：J-Lyric.net から歌詞を取ってくる（本人が「個人利用は可」と確認ずみ）。曲を入れたとき（歌詞が空なら）自動で1曲分だけ取り、曲ページの「J-Lyric.net から歌詞を取ってくる」「…→歌詞を取ってきなおす」でも取れる。入れかえるときは前の歌詞を「前の版」に残す。出どころ（リンク）と作詞・作曲を歌詞の下に出す。まとめて集めることはしない。受け口は版4（lb_lyrics）。
- 歌ネット（uta-net.com）は、機械からのアクセスを止める仕組み（Cloudflare の確認画面）があるので使わない。すり抜けもしない。
- 最高音・最低音・歌い出しを取れるサイトは、まだ許可がない（候補：KEYTUBE・カラオト・音域データ@ウィキ）。それまでは「測定不能」と音程チェックで測る形。
- 2.3.1：受け口を新しいデプロイ（版4）の URL に切りかえた（js/cloud.js の SCRIPT_URL）。
- 2.3.2：歌詞を取ってくると「別の端末の版」ができて、もとの曲から歌詞が消える不具合を直した（同じ曲の保存が重なると、自分の保存を別の端末の変更とまちがえていた。同じ曲の保存は1つずつ順番に送り、保存の途中に読みこんだ古い中身で上書きしないようにした）。受け口（Code.gs）は変えていない。
- 2.3.3：歌詞の文字を選ぶとき、iPhone の青い選ぶ印とコピーのメニューを出さないようにした。タップで1文字、横になぞると続けて選べる（下の行へも広げられる）。縦に動かしたときはふつうにスクロール。長押しはいらない。
