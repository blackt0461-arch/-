# CLAUDE.md（LAPS／旧名スケートラップ）

**ユーザーへの返事は、どんな場合も必ず日本語で書く。** ユーザーは大学生で、コードは書かない。説明は専門用語を避けて短く。質問はタッチで選べる形（AskUserQuestion）にする。

- このフォルダ（`skate/`）が「スケートラップ」。スピードスケート部の練習動画から、選手の一覧・追いかけ動画・ラップを自動で作るアプリ。中身と決まっていることは SPEC.md。
- ほかのフォルダはさわらない。
- 作業は GitLab の kotetsuworks-site の `claude/skate` ブランチで行い、そこに push する（main には送らない）。
- 公開（kotetsuworks.com）は窓口（ROOMIN の会話）がまとめてやる。できたら窓口に send_message で「何を変えたか・コミット番号・確かめたこと」を送り、本人には「窓口の会話で OK を出してください」と伝える。初めて出す時は tools/deploy/build.js の TOP_DIRS に `skate` を足す必要がある。
- まずは本人だけが使う。入口ページ（index.html）にはまだ出さない。

## 進み具合の見せ方
- 3手以上かかりそうな作業では、始めに作業リスト（TaskCreate）を作る。項目は短い日本語。取りかかる項目は進行中、終わったら完了に。
- 調べものや待ち時間が続くときは「いま〇〇を調べています」と1行で知らせる。

## 止められないためのきまり
- 鍵・トークン・.env はコードや履歴に入れない（URL にも書かない）。本人にもチャットに貼ってもらわない。
- 他の人が作った素材を新しく入れる時は出典を書く（models/README.md）。
- 100MB をこえるファイルは送らない。大量の自動操作（短い間に何度も送る）をしない。
- 練習動画そのものはリポジトリに入れない（部員が写っているため）。
