# 自動で回る台（スケートラップ用）

スマホを乗せて三脚に付ける台。アプリ（https://kotetsuworks.com/skate/）が登録した部員を見つけて、
Bluetooth で「右へ・左へ」を送り、台がスマホの向きを変える。立つ場所は変えず、向きだけ変える（首振り）。

## 買うもの（目安 合わせて 4,000〜6,000円）

| もの | 例 | 目安 |
|---|---|---|
| ESP32 の基板 | ESP32-DevKitC（秋月電子・Amazon など） | 1,500円 |
| 270度回るサーボ | DS3218MG（270°版）など 20kg クラス | 1,500〜2,000円 |
| サーボに付ける円い板（ホーン） | サーボに付いてくることが多い | 0円 |
| スマホホルダー（三脚ネジ 1/4 付き） | 100円ショップ・Amazon | 300〜800円 |
| ジャンパー線（オス-メス） | 数本 | 300円 |
| 電解コンデンサ 1000µF 10V 以上 | サーボの電気を安定させる | 100円 |
| USB ケーブルを切って作る電源線 か USB 端子台 | モバイルバッテリーから 5V をとる | 300円 |
| 三脚・モバイルバッテリー（3A 出せるもの） | 手持ちでよい | — |

## つなぎ方

| サーボの線 | つなぐ先 |
|---|---|
| 茶色（−） | モバイルバッテリーの −（GND）と ESP32 の GND |
| 赤（＋） | モバイルバッテリーの ＋5V |
| 黄色・オレンジ（信号） | ESP32 の 18番（GPIO18） |

- コンデンサはサーボの ＋ と − の間に（足の長い方が ＋）。
- ESP32 本体はモバイルバッテリーの USB からもらう（2口のバッテリーなら別の口でよい）。
- サーボの円い板にスマホホルダーをネジか強い両面テープで付け、サーボ本体を三脚の上に固定する。

## プログラムの書きこみ（1回だけ）

1. パソコンに Arduino IDE を入れる。ボードマネージャで「esp32 by Espressif」（3.x）を入れる。
2. `stand.ino` を開き、ボードを「ESP32 Dev Module」にして書きこむ。
3. 電源を入れると、台は「SkateStand」という名前で待つ。

## 使い方

1. iPhone は App Store の「Bluefy」（無料のブラウザ）でアプリを開く（Safari は Bluetooth の機械につなげない）。
2. 「その場で撮ってラップを測る」→ 線を合わせる画面の「📡 自動の台につなぐ」→「SkateStand」を選ぶ。
3. 撮影スタート。登録した部員が写ると、自分 → 部員の順でまん中に向ける。

## 安全のしかけ

- アプリから 0.5 秒何も届かないと止まる。
- 10〜260度の間しか回らない（ケーブルが巻きつかないように）。
- 急に動きすぎないよう、速さの変え方をゆるやかにしている。
